GameParty

게임 파티 모집 · 참가 신청 · 매너 리뷰 게시판  |  Spring Boot + JPA + MySQL

이 문서는 보고서에 넣을 ER 다이어그램, 시스템 구조도, 실행 흐름도, 대표 화면을 모아 둔 자료입니다.

1. 프로젝트 개요

주제같이 게임할 사람을 찾는 게임 파티 모집 게시판. 파티를 만들고, 참가 신청과 승인을 거쳐 함께 플레이한 뒤, 파티원끼리 매너 리뷰를 남겨 신뢰 점수를 쌓는다.
기술 스택Java 21 · Gradle · Spring Boot 4.2 · Spring MVC + Thymeleaf · Spring Data JPA(Hibernate) · Spring Security(BCrypt, CSRF) · MySQL 8 · Lombok · 순수 CSS/JS
DB 연동JPA 엔티티 5개(회원·게임·파티·참가 신청·매너 리뷰)를 MySQL 테이블로 매핑. 회원가입과 로그인도 DB의 회원 테이블로 처리(비밀번호는 BCrypt 암호화).

주요 기능

  • 회원 : 회원가입(아이디·닉네임 중복 검사, 주 게임 선택), 로그인/로그아웃, 마이페이지, 내 정보 수정(닉네임·주 게임·비밀번호 변경)
  • 파티 : 파티 만들기·수정·삭제, 게임별 필터와 제목 검색, 12개씩 페이지, 상세 화면 옆에서 다른 파티 둘러보기
  • 참가 신청 : 신청 → 방장 승인/거절, 신청 취소, 정원이 차면 자동 ‘인원마감’(동시 처리는 비관적 락으로 보호)
  • 매너 리뷰 : 파티 종료 후 참가자끼리 별점(1~5)과 한줄평, 같은 사람에게 1회, 받은 리뷰의 평균이 매너 점수로 표시
  • 관리자 : 대시보드 통계, 회원 관리(조회·정보 수정·권한 부여·삭제), 파티 관리(상태별 보기·강제 종료·삭제), 리뷰 관리(삭제 시 매너 점수 재계산)
  • 편의 : 게임 선택 칸(3×3 · 드래그 · 이름/장르/초성 검색), 사이트 디자인의 확인창, 시연용 더미 데이터

실행 방법

  • MySQL 8 에 접속 계정을 준비하고, 프로젝트 루트의 local-db.properties(Git 제외 파일)에 DB 계정과 관리자 계정 설정을 넣는다.
  • .\gradlew.bat bootRun 으로 실행하면 테이블이 자동 생성되고, 게임 39종과 관리자 계정이 만들어진다. 접속 주소는 http://localhost:8080.
  • 시연용 더미 데이터(회원 12명, 파티 30개, 리뷰)는 --app.seed-dummy=true 옵션으로 한 번 실행하면 들어간다.

2. ER 다이어그램

2-1. 테이블 명세

테이블설명제약 조건
member 회원로그인 계정과 프로필. 권한(USER/ADMIN), 주 게임, 받은 리뷰로 계산되는 매너 점수·평가 수를 가진다.아이디 유니크, 닉네임 유니크
game 게임모집 대상 게임 목록. 서버 시작 시 39종이 등록되고, 이미지 파일 이름(slug)을 가진다.이름 유니크
party 파티모집글. 게임과 방장(회원)을 참조하고, 최대 인원, 연락 링크, 상태(RECRUITING/FULL/CLOSED)를 가진다.game_id, host_id 외래키
party_member 참가 신청회원과 파티의 N:M 관계를 푼 연결 테이블. 신청 상태(PENDING/APPROVED/REJECTED)와 신청 시각을 가진다. 방장도 ‘참가 중’으로 함께 등록된다.(party_id, member_id) 복합 유니크
party_review 매너 리뷰종료된 파티에서 참가자끼리 남기는 별점(1~5)과 한줄평. 작성자와 받는 사람은 모두 회원을 참조한다.(party_id, reviewer_id, target_id) 복합 유니크

업무 규칙 (서비스 계층에서 검증)

  • 참가 신청은 모집중 파티에만 가능하고, 내 파티와 이미 신청한 파티에는 신청할 수 없다.
  • 승인은 정원에 여유가 있을 때만 가능하며, 승인 인원이 정원이 되면 파티가 자동으로 인원마감이 된다. 참가 취소·정원 변경으로 자리가 나면 다시 모집중이 된다.
  • 리뷰는 종료된 파티에서, 승인된 참가자끼리, 자기 자신을 제외하고, 같은 파티·같은 사람에게 한 번만 남길 수 있다.
  • 리뷰를 남기면 받은 사람의 매너 점수(평균, 소수 첫째 자리)가 갱신되고, 리뷰·파티·회원이 삭제되면 남은 리뷰로 다시 계산한다.
  • 관리자 기능(/admin/**)은 ADMIN 권한만 접근하며, 일반 회원은 403 으로 차단된다. 자기 자신과 마지막 관리자는 권한 변경·삭제할 수 없다.

5. 화면 구성

실제 실행 화면입니다. (시연용 더미 데이터 사용)

5-1. 메인 화면

게임 이미지가 흐르는 첫 화면. 아래로 내리면 소개와 규칙이 이어진다.

5-2. 로그인

Spring Security 폼 로그인.

5-3. 회원가입

아이디·비밀번호·닉네임과 주 게임(3×3 선택 칸, 드래그·검색)을 입력한다.

5-4. 파티 찾기

왼쪽 게임 목록으로 필터하고, 제목으로 검색한다. 한 페이지에 12개.

5-5. 파티 만들기

게임 선택 칸(3×3, 드래그, 이름·장르·초성 검색)과 제목·인원·연락 링크를 입력한다.

5-6. 참가 신청 (참가자 화면)

모집중 파티에서 참가 신청을 하고, 오른쪽에서 다른 파티를 둘러볼 수 있다.

5-7. 신청 승인 · 거절 (방장 화면)

방장은 신청 대기 목록에서 승인 또는 거절한다. 정원이 차면 자동으로 인원마감이 된다.

5-8. 종료된 파티와 매너 리뷰

종료된 파티에서 참가자끼리 별점과 한줄평을 남기고, 리뷰 목록이 보인다.

5-9. 마이페이지

내가 만든 파티, 신청 현황, 받은 리뷰와 매너 점수를 모아 본다.

5-10. 내 정보 수정

닉네임, 주 게임, 비밀번호(현재 비밀번호 확인 후)를 바꾼다.

6. 관리자 화면

6-1. 대시보드

회원·파티(상태별)·리뷰·게임 통계와 최근 가입 회원, 최근 파티.

6-2. 회원 관리

아이디·닉네임 검색, 정보 보기, 권한 부여, 삭제.

6-3. 회원 정보

가입 정보, 만든 파티, 신청한 파티, 받은 리뷰, 활동 요약과 정보 수정.

6-4. 파티 관리

전체·모집중·인원마감·종료 버튼으로 상태별 보기, 강제 종료, 삭제.

6-5. 리뷰 관리

모든 리뷰를 보고 삭제한다. 삭제하면 받은 사람의 매너 점수를 다시 계산한다.

6-6. 확인창

되돌릴 수 없는 작업 전에 사이트 디자인의 확인창을 띄운다.
